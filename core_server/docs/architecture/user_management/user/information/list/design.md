# 列表系统

账户所有的列表，包含多个resource.

列表按内容分有三种：
- 单种列表.
- 有限种类列表
- 混合列表.
包含多种resource.

列表按是否公开也分为两种：
- 公开列表.
可以被他人检索.
- 私有列表.
仅用户自身可见.

列表的数据结构为：
- 账户UID.
- ID.
同一账户下唯一.
- 内容类型.
可为空，表示不限制.
- 公开状态.
为真值，真表示公开，假表示私有.
- 简介.
- 内容.
储存UUID，不允许出现重复的UUID.

## 创建列表
接收如下参数：
- 账户UID.
- ID.
- 内容类型.
可为空.
- 公开状态.
- 简介.
可为空.
- 内容.

## 修改列表内容和简介
接收如下参数：
- 账户UID.
- ID.
- 新简介.
覆盖列表的旧简介，空则表示不修改.
- 新内容.
覆盖列表的旧内容，空则表示不修改.

## 修改列表公开状态
接收如下参数：
- 账户UID.
- ID.
- 公开状态.
为真值，和原状态相同则不操作.

## 获取列表内容
接收以下参数：
- 账户UID.
- ID.

## 检索列表
接收一串字符串对公开列表的简介和ID进行检索，排序使用推荐系统.

## 删除列表
接收如下参数：
- 账户UID.
- ID.
