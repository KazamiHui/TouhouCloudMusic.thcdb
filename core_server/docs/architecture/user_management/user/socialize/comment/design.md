# 评论系统

评论有一种为辅助审核所存在的，这种评论称为辅助评论，也就是对提案的讨论.
评论的数据结构为：
- UUID.
- 对象的UUID.
- 发出的账户.
- 内容.
- 时间戳.

辅助评论的数据结构为：
- UID.
类型为整数，默认延续最后一条的UID序列，如果没有则从1开始.
- 审核对象的类型.
`tag`、`resource`、`socialize`中的一种.
- 审核对象UID.
- 上一级评论的UID.
如果为顶级辅助评论则为空.
- 发出的账户.
- 内容.

辅助评论在关联的审核对象关闭后自动删除.

## 获取resource的评论
接收一个resource对象的UUID，返回这个对象的评论的UUID.

## 获取评论数据
接收一个UUID，获取评论除UUID和对象UUID外的数据.

## 创建评论
接收如下参数：
- resource对象的UUID.
- 账户UID.
- 内容.
经过关键词排查过后合格才可以创建.

创建评论的同时也在`socialize_review`系统创建一个审核对象.

## 删除评论
接收一个UUID，物理删除这个UUID的对应的评论及其子评论.

## 获取审核对象的讨论
接收如下参数：
- 审核对象类型.
具体见上文.
- 审核对象UID.

返回这个审核对象的辅助评论的UID.

## 获取辅助评论数据
接收一个UID，获取辅助评论的内容和上一级评论的UID.

## 创建辅助评论
接收如下参数：
- 审核对象类型.
具体见上文.
- 审核对象的UID.
- 发起的账户.
- 内容.

## 删除辅助评论
接收一个UID，删除这个UID对应的辅助评论及其子辅助评论.

## 举报评论、辅助评论
提供以下参数：
- 评论类型.
有且只有评论和辅助评论两种.
- 唯一标识符.
如果为评论，则为UUID；如果为辅助评论，则为UID.
- 举报描述.
- 发起举报的账户UID.

复制举报对象的以下内容：
- 唯一标识符.
- 发起的账户.
- 内容.
- 关联的所有父子评论的UUID.
只有举报对象为评论时才复制，辅助评论没有.

结合`举报描述`和`发起举报的账户的UID`来产生一个comment类型举报.
