# 推荐系统

该系统不做复杂推荐，减少客户端重复实现.
推荐系数为核心机制，默认为0，推荐系数分为公有推荐系数与私有推荐系数.

公有推荐系数结构为：
- resource的UUID.
- 推荐系数.
该系数的计算规则在后续给出.

私有推荐系统的结构为：
- 账户UID.
- Tag的UID.
- 推荐系数.
同样在后续给出.

## 公有推荐系数的计算方法
公有推荐系数为以下内容的和：
- 所在的公开列表的数量.
- Tag的数量.
- 近一个月的revision_node的数量.

## 私有推荐系数的计算方法
私有推荐系数为以下内容的和：
- 含有Tag的resource所在的私有列表的数量.
- 上面的数量与含有Tag的resource所在的公开列表的数量的比值.
