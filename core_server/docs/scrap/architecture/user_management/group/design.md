# group

User组成的集合，具有一定规则.

group的数据结构为：
- UID.
内部维护自增.
- ID.
在表中必须唯一.
- 停止活动.
满9个月则对其中所有账户进行销户，满一年将自身ID置空并将其中所有账户执行即刻销户（与销户满90天的行为相同）.
- 账户主权限.

预留以下两个group：
- `admin`，成员只有一个admin账户，`账户主权限`为空，UID为0.
- `individual`，`账户主权限`为`resource_rectify`,`create_personal_list`权限，UID为1.
