# 列表系统

账户所有的列表，包含多个resource.

列表按内容分有三种：
- 单种列表.
- 有限种类列表
- 混合列表.
包含多种resource.

列表按是否公开也分为两种：
- 公开列表.
可以被他人检索.
- 私有列表.
仅用户自身可见.

列表的数据结构为：
- 账户UID.
- ID.
同一账户下唯一.
- 内容类型.
可为空，表示不限制.
- 公开状态.
为真值，表示列表是公开的或私有的.
- 简介.
- Tag.
储存tag的UID.
- 内容.
储存UUID，不允许出现重复的UUID.

## 创建列表
接收如下参数：
- 账户UID.
- ID.
- 内容类型.
可为空.
- 公开状态.
- 简介.
可为空.
- Tag.
可为空.
- 内容.

## 修改列表键值
接收如下参数：
- 账户UID.
- ID.
- 修改的表键.
为键值对，键名为修改的表键，键值为表键的新值.  
只可以修改列表的公开状态、简介、内容、ID、Tag.

## 获取列表内容
接收以下参数：
- 账户UID.
- ID.

## 检索列表
接收一串字符串对公开列表的简介和ID进行检索，使用私有推荐系数排序，私有推荐系数请见[推荐系统](../../../../recommendation/design.md).

## 删除列表
接收如下参数：
- 账户UID.
- ID.
