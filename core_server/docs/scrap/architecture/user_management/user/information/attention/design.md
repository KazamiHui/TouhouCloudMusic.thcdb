# 关注系统

该系统功能正常实现依赖于通知系统.  
关注的对象有且只有resource对象.  
数据结构为：
- 账户UID.
- 关注的对象.
- 关注的对象的类型.
- 关注的内容.

---
**功能**
- [获取关注列表]
- [创建关注]
- [修改关注的内容]
- [删除关注]
---

## 获取关注列表
接收如下参数：
- 账户UID.
- 关注的对象类型.
可选.

## 创建关注
接收如下参数：
- 账户UID.
- 关注的对象.
- 关注的内容.
为以下两种：
    - modify.
    需要指定关注的一个或多个字段.
    - comment.
    - released.
    对[社团、公司](../../../../resource/team/design.md)、[文化作品创作者](../../../../resource/artist/design.md)可用，其他不可用.

## 修改关注的内容
接收如下参数：
- 账户UID.
- 关注的对象.
- 新的关注的内容.
覆盖旧的关注的内容.

## 删除关注
接收以下参数：
- 账户UID.
- 关注的对象.
