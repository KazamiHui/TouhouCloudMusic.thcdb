# 产品

一般以合辑、精选集、专辑等形式出现，单曲和demo相对少见.

`相关非文本内容`包含以下：
- 封面.
- 封底.
- 内页插绘.

数据结构为：
- 标题.
为一个集合.
- 产品类型.
包含以下类型：
    - album.
    完整专辑，一般不少于8首.
    - EP.
    这里使用美国标准，即小于8首的专辑.
    - single.
    单曲.
    - compilation.
    合辑，包含一些歌曲，不一定是一个系列的.
    - greatest_hits.
    精选辑，一般内容都来自一个特定的文化作品创作者、社团或公司.
    - demo.
    样本录音.
    - other.
- 曲目.
为一个有序集合，关联[歌曲表](../song/design.md)中的歌曲.
- 发行日期.
- Tag.
- 描述.
- 制作人员列表.
为一个集合，关联[文化作品创作者](../artist/design.md)、[社团或公司](../team/design.md).

其中`标题`和`简介`为逻辑表键，与[自然语种内容表](../language/design.md)结合.
